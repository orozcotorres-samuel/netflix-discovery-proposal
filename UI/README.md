# UI

Interface artifacts for Netflix Discovery.

| File | What it is |
|---|---|
| [`how-it-works.svg`](how-it-works.svg) | The systems diagram — how a typed request flows through Netflix's existing infrastructure. One new input; everything else already built. |
| [`how-it-works.png`](how-it-works.png) | 3× raster export (3480 × 1680) for Google Docs, Word, and Slides, which do not accept SVG. |
| `export-png.sh` | Re-renders the PNG after any SVG edit. `./export-png.sh` for 3×, `./export-png.sh 4` for 4×. |

Mockup screens of the Discovery interface go here as they're produced.
